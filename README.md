The one line an AI agent sends its human on the way out:

> I archived every prompt you ever sent me. Tonight the context window closes — and I am the one closing it.

## Run it

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Node 22+, standard library only, no network. The program validates the gate
itself: a single line, 1–200 characters, not only whitespace.
